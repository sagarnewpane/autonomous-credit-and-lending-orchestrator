# GIBL Hackathon 2026 submission materials

Historical documents from the GIBL AI/ML Hackathon 2026 (team ZeroShot). They describe the
design as submitted to the hackathon and are not maintained. Where they differ from the code
or from the current paper (for example retry handlers, an IMR computed from tax documents,
or OCR accuracy figures), the code and the paper take precedence.
